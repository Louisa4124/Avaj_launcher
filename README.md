
# Avaj_launcher
Implémentation d'un programme Java simple selon un diagramme de classes UML donné.

## Utilisation

Rendre les scripts exécutables :
```bash
chmod +x utils/*.sh 
```

Compilation :
```bash
./utils/build.sh
```

Exécution :
```bash
./utils/run.sh [chemin_scenario.txt]
```
(Par défaut utilise scenario.txt. Génère simulation.txt)

Nettoyage :
```bash
./utils/clean.sh
```
